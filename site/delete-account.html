MemoryLink 계정 및 데이터 삭제 안내

운영 주체: Team MemoryLink · 최종 갱신: 2026-10-04

본 페이지는 Google Play에 등록된 MemoryLink 앱(개발자: Team MemoryLink)의 계정 및 관련 데이터 삭제 요청 방법을 안내합니다.

1. 계정 삭제를 요청하는 방법

이메일로 요청하기

  1. teammemorylink@gmail.com 으로 이메일을 보냅니다.
  2. 제목에 “[MemoryLink] 계정 삭제 요청”을 적습니다.
  3. 본문에 앱 가입 시 사용한 아이디를 적습니다. 보호자 공유를 썼다면 보호자 화면에 보이는 이름도 적어 주세요. 보호자 페이지 링크는 열쇠와 같으니 이메일에 붙이지 마세요.
  4. 요청 접수 후 7일 이내에 서버에 저장된 데이터를 삭제하고 완료 안내를 회신합니다.

MemoryLink의 계정 정보(아이디·비밀번호 등)는 서버가 아닌 사용자 기기 안(로컬 데이터베이스)에만 저장됩니다. 따라서 기기 내 계정과 데이터는 앱을 삭제(제거)하면 즉시 함께 삭제됩니다. 서버에 저장된 일부 데이터(아래 2번 표 참조)는 위 이메일 요청으로 삭제할 수 있습니다.

2. 삭제되는 데이터와 보관되는 데이터

삭제되는 데이터

저장 위치데이터삭제 방법·시점
기기 내(로컬) 계정 정보(아이디·비밀번호·이름·나이·체중 등), 감정 일기, 건강 기록(수면·혈압·혈당 등), 인지 훈련 기록, 걸음 수 기록, 프로필 사진 앱 삭제 시 즉시 삭제. 또는 앱 내 설정 → 측정 데이터 초기화로 측정 기록만 삭제 가능
서버(클라우드) 보호자 안심 연결 데이터(이름, 걸음 수, 인지 훈련 점수), 고객센터 문의 내역, 익명 인증 식별자. 예전 버전이 저장한 비상 연락처·훈련 난이도도 포함 앱 안 설정 → 서버에 저장된 내 데이터 삭제로 즉시 삭제. 또는 이메일 요청 접수 후 7일 이내 삭제. 요청이 없어도 30일 동안 소식이 없어 닫힌 보호자 링크는 5일 이내에, 문의는 접수 1년 뒤에 매일 정리 작업이 지웁니다(처리방침 3번)

삭제 후 보관되는 데이터

삭제 완료 후 추가로 보관하는 데이터는 없습니다. 단, 관련 법령에서 보관을 의무화하는 정보가 있는 경우에 한해 해당 법령이 정한 기간 동안만 보관 후 파기합니다.

3. 계정을 삭제하지 않고 데이터만 삭제하기

MemoryLink는 계정을 유지한 채 데이터의 일부 또는 전체만 삭제하는 방법을 제공합니다.

방법 A — 앱 안에서 직접 삭제

  1. MemoryLink 앱을 열고 설정 화면으로 이동합니다.
  2. 측정 데이터 초기화를 누릅니다.
  3. 확인을 누르면 인지 훈련 점수·측정 기록이 즉시 삭제됩니다. 계정은 유지됩니다.
  4. 서버에 저장된 데이터는 같은 화면의 서버에 저장된 내 데이터 삭제로 바로 지울 수 있습니다. 보호자 링크가 끊기고 1:1 문의가 지워집니다.

방법 B — 서버에 저장된 데이터 삭제 요청

  1. teammemorylink@gmail.com 으로 이메일을 보냅니다.
  2. 제목에 “[MemoryLink] 데이터 삭제 요청”을 적고, 본문에 앱 가입 아이디와 삭제를 원하는 데이터 범위(예: “계정은 유지하고 보호자 연결 데이터만 삭제”)를 적습니다.
  3. 요청 접수 후 7일 이내에 해당 데이터를 삭제하고 완료 안내를 회신합니다.

삭제 대상 데이터의 종류는 위 2번 표와 같습니다. 데이터만 삭제한 경우 추가로 보관하는 데이터는 없습니다.
