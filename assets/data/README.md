# 치매안심센터 공공데이터 — 채워 넣어야 하는 파일

`dementia_centers.csv`는 지금 **헤더만 있는 자리표시자**입니다.
파일을 교체하면 `/dementia_centers` 화면이 바로 동작합니다. 앱 코드는 손댈 필요가 없습니다.

## 왜 비어 있나

CSV 다운로드는 사용자 승인이 필요한 행위라 자동으로 받지 않았습니다.
공공데이터포털 미리보기에는 50행(서울·부산·대구)만 노출되는데,
17개 시도 중 3개만 담긴 파일을 넣으면 다른 지역 사용자가
"우리 동네엔 센터가 없다"고 오해할 수 있어 부분 데이터도 넣지 않았습니다.

## 교체 방법 (1분)

1. https://www.data.go.kr/data/15138421/fileData.do 접속
2. **다운로드** 버튼 클릭 (로그인 불필요, 이용허락범위 제한 없음)
3. 받은 CSV를 **UTF-8로 저장**한 뒤 이 폴더에 `dementia_centers.csv` 이름으로 덮어쓰기
4. `flutter run` — 끝

### EUC-KR로 받아졌다면

data.go.kr CSV는 EUC-KR인 경우가 있습니다. Dart 표준 라이브러리에 EUC-KR 디코더가 없어
앱이 "CSV가 UTF-8이 아닙니다"라고 안내합니다. PowerShell에서 변환하세요:

```powershell
$bytes = [System.IO.File]::ReadAllBytes("원본.csv")
$text  = [System.Text.Encoding]::GetEncoding(51949).GetString($bytes)  # 51949 = EUC-KR
[System.IO.File]::WriteAllText("dementia_centers.csv", $text, (New-Object System.Text.UTF8Encoding($false)))
```

마지막 인자 `$false`는 BOM을 붙이지 않겠다는 뜻입니다. BOM이 붙어도 파서가 제거하므로
둘 다 동작하지만, 없는 쪽이 깔끔합니다.

## 스키마

파서는 **컬럼 이름으로** 매핑하므로 순서가 바뀌어도 안전합니다.
필수 컬럼은 `치매안심센터명`, `시도`, `시군구` 세 개이며, 없으면 앱이 명시적으로 실패를 알립니다.

| 컬럼 | 용도 |
|---|---|
| 치매안심센터명 | 카드 제목 |
| 시도 / 시군구 | 지역 선택 드롭다운 |
| 주소1 / 주소2 | 주소 표기 |
| 위도 / 경도 | 지도 열기 (없으면 지도 버튼 숨김) |
| 전화번호 | 전화 걸기 (없으면 전화 버튼 숨김) |
| 홈페이지 | 웹 열기 (스킴 없으면 https:// 자동 부착) |
| 우편번호 / 팩스번호 / 개소일 | 모델에는 있으나 현재 화면 미사용 |
| 도로명·법정동·행정동코드 | 미사용 (모델에 담지 않음) |
