# 보완 검토: 기관 평가결과 연결과 예방교실 평가변수

검토일: 2026-10-05. 기존 설문·권리 검토서와 별도로 작성한 보완자료. 검사 문항·임상 절단점을 재현하지 않았다.

## 1. 바로 사용할 결론 문구

> 기관에서 적법하게 시행·생성한 평가결과를, 해당 도구의 계약과 기관의 데이터 처리·공유 권한이 허용하는 범위에서 연결하는 방안을 검토한다. 문항을 넣지 않고 총점만 저장하더라도 도구별 라이선스 검토가 면제되는 것은 아니다. 승인 범위가 확인되기 전에는 실제 점수 연결을 활성화하지 않으며, 앱에서 규준·절단점·진단분류·임상적 개선 여부를 새로 계산하지 않는다.

**총점만 가져오면 이용권 문제가 없다는 일반적 허락은 확인하지 못했다.** 그렇다고 모든 숫자 기록에 반드시 별도 라이선스가 필요하다고 확정한 것도 아니다. 기존 계약, 결과의 내용, 상용 서비스의 역할, 이용자/수신자, 지역별 법률에 따라 판단해야 한다.

'센터 소유 척도' 대신 **'기관 주도·관리 평가'**로 표현한다. 기관은 평가와 기록의 관리주체일 수 있지만 척도·번역·규준·출판사 보고서의 지식재산권까지 소유하는 것은 아니다.

## 2. 결과와 도구 구현을 분리하는 다섯 단계

| 처리 대상 | 의미 | 사전 조건 |
|---|---|---|
| 평가 실시 사실·일자·기관·담당자 | 최소 업무연계 메타데이터 | 그 사실도 개인의 건강 관련 정보일 수 있다. 처리 목적·수탁 관계·접근/공유 권한 확인. 도구 명칭 표시도 실제 계약/표시조건 검토 |
| 기관이 적법하게 생성한 개별 총점의 수기 입력/전달 | 기존 결과의 기록·전달, 검사 시행과는 구별됨 | **조건부 후보.** 기관의 현재 라이선스가 외부 상용 플랫폼 처리·저장·수신자 표시·재배포를 허용하는지 문서 확인. 공개된 총점 전용 일반 면책 조항은 찾지 못함 |
| 기존 기관 해석·분류표시의 전달 | 누가 언제 판단한 것인지가 있는 과거 기록 | 기록 생성/전달 권한과 임상 맥락 확인. '기관이 당시 기록한 해석'으로 출처 고정. 현재 앱 판단처럼 재표시하지 않음 |
| 보고서 PDF/사진·서식·문항별 반응·규준표의 저장/재표시 | 출판물 또는 보호된 검사자료의 복제 가능성이 커짐 | 총점 기록 허락과 별개. 보고서/자극/문항/표의 권리, 수신자 자격, 재배포 범위 확인. 기본 설계에서는 제외 |
| 자동채점·나이/교육 보정·백분위·새 위험등급·진단·추세 해석 | 도구의 알고리즘/규준 또는 새로운 임상적 출력 구현 | 별도 권리와 임상·규제 검토 필요. 총점 입력 허락만으로 구현 금지. 단순 전후 차이·집단 집계·연구/홍보 재이용도 목적과 계약 범위를 별도 확인 |

명칭을 정확히 적는 것, 로고·공식 보고서 디자인을 사용하는 것, 권리자가 인증한 제품처럼 홍보하는 것은 서로 다르다. 출판사 로고·공식검사 배지·인증/제휴 주장은 명시적 허락 없이는 사용하지 않는다. 모든 명칭 표시가 금지된다는 뜻은 아니다.

APA의 공식 설명도 개별 결과·총점 등 **test data**와 검사문항·매뉴얼·채점키/알고리즘 등 **test materials**를 구분하면서, 공개 가능 범위는 상황·정책·법률·목적을 고려해야 한다고 설명한다. 이는 구분에 도움이 되는 전문단체 설명이지 한국 상용 SaaS에 대한 법적 허락은 아니다. [R1]

### 허락을 확인할 때 묻는 최소 질문

'기관이 공식 방식으로 시행한 [정확한 한국어판/판본]의 **이미 산출된 총점·시행일·판본·기관 작성 해석만**, 문항·자극·규준·채점코드 없이, 지정 기관의 수탁자인 MemoryLink가 저장하고 [지정 직원/본인/승인된 보호자]에게 보여주려 합니다. 이 처리가 기존 계약에 포함됩니까? 명칭 표시, 전후 차이/그래프, CSV/PDF 내보내기, 다기관 운영, 보관/계약 종료 후 유지에 별도 허락이 필요합니까?'

이것은 검토용 질문 틀이며 실제 연락은 하지 않았다. 연락 시 실제 대상·조직·처리자·범위를 특정하고 건강정보를 예시로 첨부하지 않는다.

## 4. 정상군 예방교실에서 SGDS-K·SMCQ의 위치

2026 치매정책 사업안내의 예방교실 사전·사후 평가에 두 도구가 제시되어 있다. 따라서 **센터의 기존 운영평가와 연결하기 좋은 후보**다. 그러나 MemoryLink 파일럿의 앱 내 표준 설문 또는 앱 효과의 필수 1차 평가지표가 되는 것은 아니다. 기관 지침상 평가 시행과 앱 연구에서의 추가 수집·재이용은 구별해야 한다. [R7]

### 권장 구조

- 1차 목적: 참여자가 활동을 이해하고 선택/중단할 수 있는지, 실제로 이용 가능한지, 직원 업무와 참여자 부담이 허용 가능한지
- 선택적 2차 변수: 기관이 적법하게 시행한 SGDS-K의 **자가보고 우울증상**, SMCQ의 **주관적 기억불편**. 권리·데이터 재이용·동의가 정리된 경우에만 연결
- 두 결과를 더하거나 정규화하여 '인지건강', '치매예방률', '인지기능 회복'으로 만들지 않음
- '인지선별검사 정상군'은 우울증상이나 주관적 기억불편이 전혀 없는 집단이라는 뜻이 아님

### 측정 한계와 파일럿에서 확인할 것

| 측정 문제 | 해석 | 권장 대응 |
|---|---|---|
| 낮은 초기 증상/불편 | 낮은 점수에 모인다면 더 개선될 여지가 작아 변화 탐지가 어렵다 | 이는 **해당 표본에서 검증할 설계상 가능성**이며 모든 정상군에 이미 입증된 바닥효과라고 단정하지 않는다. 최소/최대점수 집중률, 분포, 응답 누락을 먼저 보고 |
| 상한에 가까운 높은 초기 점수 | 점수의 범위 제한 때문에 더 악화된 변화도 덜 드러날 수 있다 | 천장효과도 실제 분포로 점검. '정상 인지군이라 발생하지 않는다'고 가정하지 않음 |
| 이분형 문항 | 작은 주관적 변화가 응답변경으로 나타나지 않거나 한 응답 변화가 과대해석될 수 있음 | 작은 점수차를 임상적으로 의미 있는 개선으로 선언하지 않음. 한국어 정상군 앱 파일럿의 최소중요차이는 미확인 |
| 기분·기억에 대한 자기보고 | SMCQ는 객관적 수행검사와 동일하지 않다. 원저에서 기분과의 연관이 관찰됨 | 점수 감소는 불편감 감소로 기술. 인지기능 향상·병리 변화로 바꾸지 않음. SGDS-K 변화도 기분/증상 변화이며 인지효과가 아님 [R9,R10] |
| 교육·관심·사회적 접촉·보고기준 변화 | 앱 또는 수업 후 본인의 기억에 더 주목하거나 응답기준이 달라질 수 있다 | 이런 변화는 가능한 설명으로 남겨두고, 점수 상승을 바로 악화로 판정하지 않음. 동시 치료·생활사건·평가모드·지원 여부를 최소한의 맥락으로 기록 |
| 비의료 앱의 전후 단일군 비교 | 재검사·선택적 탈락·평균회귀·기관 프로그램 효과를 분리하기 어려움 | 사용성과 완료가능성 중심으로 결론. 원점수 변화는 탐색적으로 보고, 비교효과 연구는 별도 계획 |

Bae/Cho의 SGDS-K 타당화는 한국 노인 정신과 환자를 중심으로 했다. 한국어판의 진단적 타당도가 정상 예방교실에서의 앱 개입 **변화 민감도**를 자동 입증하지 않는다. SMCQ 원저도 자기보고 도구로 개발된 것이며, 검사 신뢰도와 치료 반응성은 다른 속성이다. [R9,R10]

### 평가시점의 함정

지침은 운영상 일정 조건에서 직전 사후평가를 다음 사전평가로 갈음하도록 한다. **그 과거 값이 MemoryLink를 시작하기 직전의 연구 기준값을 뜻하지는 않는다.** 실제 앱 시작일과 평가일의 간격을 기록하고, 연구 목적의 새로운 평가가 필요하면 기관이 적절성·응답부담·권한을 검토한다. 비교할 수 없는 시점을 같은 '앱 전/후' 그래프로 연결하지 않는다. [R7]

## 5. 우려되는 응답의 전문적 확인

앱에 두 도구를 직접 넣지 않고 결과만 연결해도 기관은 우려되는 응답/결과에 대응할 책임자를 정해야 한다. 아래는 운영 제안이며 새 임상 절단점이 아니다.

1. 시작 전 기관의 정식 매뉴얼과 기존 진료·상담 연결 기준, 검토 담당자, 대체 담당자, 업무시간·응답예정 시간을 정한다
2. 평가에서 우려가 있으면 교육받은 기관 인력이 원래 평가·응답자·상황을 확인하고 필요한 전문가 상담/재평가를 연결한다. 총점 하나만으로 자동 진단하지 않는다
3. 갑작스러운 기능 변화나 안전에 대한 직접 호소는 예정된 사후평가나 총점 계산을 기다리지 않고 기관의 긴급 대응 절차로 다룬다
4. 앱 알림은 실제 담당자가 확인할 수 있는 체계에서만 사용한다. 읽음·조치·연결 완료를 구분하고 '자동으로 의료진이 실시간 확인한다'고 암시하지 않는다
5. 참여자 동의 없이 결과를 모든 가족에게 보내지 않는다. 보호자의 역할과 접근범위를 사전에 정한다
6. 낮은 점수 또는 '정상' 기관 기록이 있어도 당사자의 현재 우려를 무시하지 않는다

## 6. 이번 도입의 go/no-go

- **가능:** 독자 비진단 체크인과 데이터 구조 설계, 합성자료로 화면 검토, 평가 실시/검토 흐름에 대한 기관 협의
- **조건부:** 기관이 생성한 실제 총점·판본·해석을 지정 사용자에게 전달. 도구 계약/권리 적용범위와 데이터 처리 권한을 확인한 뒤 활성화
- **보류:** 이름 있는 점수의 상용 외부 표시 권한이 불명확하거나, 보고서/규준/알고리즘을 복제하거나, 앱이 새 임상 분류·개선 판단을 생성하는 경우
- **미확인을 해소하지 못할 때:** 임상 평가결과는 원기관의 기존 시스템에 두고 MemoryLink는 승인된 최소 업무상태와 참여활동 기록만 다루는 구성을 기관과 검토
