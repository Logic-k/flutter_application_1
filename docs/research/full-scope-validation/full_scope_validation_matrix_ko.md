## 첫 화면 요약

MemoryLink는 한 사람이 여러 역할을 가질 수 있는 제품으로 정리한다. 진단 정보는 선택 입력이며, 입력하지 않거나 모르는 상태도 정상 경로다. 접근성/도움 수준은 진단명과 독립적으로 저장한다. 앱 점수나 활동 결과는 정상, MCI, 치매를 판정하지 않는다.

현재 내부 검토로 가능한 단계는 근거-목적-버전 정리, 화면/기록 흐름 점검, 합성 데이터 기반 저장 검증, 전문가 데모 준비다. 실제 이용자 참여 전에는 저작권·사용허가, 전문가 내용 검토, 기관 절차, 동의·중단·기록 체계가 먼저 확정되어야 한다. 효과 검증은 별도 연구로 분리한다.

| 우선순위 | 제품 적용안 | 현재 상태 | 다음 검증 |
|---|---|---|---|
| 1 | 공통 안전·기록 레이어: 진단 미입력 허용, 도움 수준, 중단/불편/기술 문제 기록, 콘텐츠 버전 | 일부 구현, 일부 제안 | 합성 데이터로 저장·중단·권한·화면 흐름 확인 |
| 2 | 대표 활동: 함께 고르기, 일상 회상, 도형 맞추기, 문장 읽기, 일정 준비 | 일부 구현, 일부 제안 | 임상 효과가 아니라 사용성·운영 가능성 검증 |
| 3 | 표준 설문 후보: SMCQ, KDSQ-C, K-AD8, K-IADL/K-ADL, SGDS-K, ZBI, KQOL-AD | 후보만 정리, 구현 금지 상태 | 원문 권리·한국어판·채점/해석 사용허가 확인 |
| 4 | 기업·기관 제안 근거 | 문헌/공식 자료 기반 매트릭스 작성 | 전문가 검토 기록과 보류 조건 명시 |

## 적용 원칙

진단 도구와 인지 활동은 분리한다. 설문은 선별·관찰·부담·삶의 질 등 목적별로 다르며, 자기보고, 보호자 관찰, 전문가 평가, 보호자 본인의 부담을 한 점수로 합치지 않는다. 활동 완료 횟수는 사용 기록일 뿐이며, 분모가 있는 참여율·순응도·충실도와 구분한다.

검증 순서는 고정한다.

1. 근거, 목적, 버전 확정
2. 자산, 권리, 전문가 내용 검토
3. 합성 데이터 기반 소프트웨어·권한·중단·저장 흐름 점검과 화면 목업 검토
4. 기관 절차에 따른 감독 하 사용성·실행 가능성 검증
5. 효과 검증은 별도 연구로 설계

표본 수, 통과율, 효과 크기는 이 문서에서 만들지 않는다. 모두 "합의 필요"로 둔다.

## 활동 매트릭스

### A1. 함께 고르기

- 대상/목적/응답자: 일반 고령자, MCI 진단자, 치매 당사자와 보호자 공동 사용. 목적은 선호 주제 선택과 가벼운 대화 시작이다. 응답자는 사용자 또는 보호자 보조 입력자다.
- 근거 문헌·공식 URL·대상: Cognitive Stimulation Therapy는 소그룹 치매 대상 구조화 인지 자극 원칙을 사용한다. 공식 매뉴얼/교육 정보는 https://www.ucl.ac.uk/international-cognitive-stimulation-therapy/ 이다. iCST 원문은 치매 당사자와 보호자 dyad를 대상으로 한 가정 기반 caregiver-led iCST 무작위대조시험이다: https://doi.org/10.1371/journal.pmed.1002269
- 원문 원리와 새 설계 차이: 원문은 정해진 세션 구조, 촉진자, 회기 충실도, 주제 활동을 포함한다. 현재 함께 고르기는 표준 CST가 아니라 주제 선택과 도움 수준 기록을 위한 짧은 앱 활동이다.
- 현재 상태: 구현됨. `topic_choice_v1`, 주제 선택, 도움 수준, 자기 연습 여부, 콘텐츠 버전, 응답 코드 저장. 대화 내용은 저장하지 않음.
- 미검증: 실제 센터 진행자 사용성, 보호자 보조 입력 이해도, 중단/불편 사유 UI, 주제 문화 적합성.
- 권리/전문가 확인 담당: 제품 책임자와 임상/작업치료/치매센터 전문가. CST 명칭·구조를 차용할 경우 별도 권리 확인 필요.
- 검증 방법/통과 조건: 합성 사용자로 선택-완료-미선택 흐름을 실행하고 저장 필드가 의도대로 남는지 확인. 통과율은 합의 필요.
- 보존 증거: 화면 캡처, DB 레코드, 콘텐츠 버전, 테스트 로그, 전문가 코멘트.
- 현재 내부 검토/보류 조건: 내부 데모 가능. 실제 참여자 사용은 동의·중단·불편 기록과 전문가 검토 전까지 보류.

### A2. 일상 회상

- 대상/목적/응답자: 일반 고령자, MCI 진단자, 치매 당사자. 목적은 일상 회상과 자기 기록이다. 응답자는 본인, 필요 시 보호자 보조.
- 근거 문헌·공식 URL·대상: 회상 기반 접근과 의미 있는 일상 활동은 치매 돌봄 프로그램에서 널리 사용된다. CST/iCST 자료는 https://www.ucl.ac.uk/international-cognitive-stimulation-therapy/ 를 참고한다. GREAT 연구는 목표 지향 인지재활을 초기 치매 대상에서 평가했다: https://pubmed.ncbi.nlm.nih.gov/30217629/
- 원문 원리와 새 설계 차이: 연구 원문은 훈련된 치료자, 목표 설정, 반복 세션, 결과 측정이 있다. 현재 기능은 자유 텍스트 일상 회상이며 표준 회상치료나 GREAT 프로토콜이 아니다.
- 현재 상태: 구현됨. 5개 일상 질문의 텍스트 입력이 있으나 완료 기록에는 점수 없이 활동 완료가 저장된다.
- 미검증: 개인정보 최소화, 민감정보 입력 경고, 보호자 대리 입력 표시, 저장 범위와 삭제 흐름.
- 권리/전문가 확인 담당: 개인정보/보안 담당, 임상 전문가, 제품 책임자.
- 검증 방법/통과 조건: 합성 문장 입력으로 로컬 저장 범위와 완료 기록을 확인하고, 민감정보 안내 문구를 전문가가 검토한다. 통과율은 합의 필요.
- 보존 증거: 테스트 계정 스크린샷, 저장 여부 체크리스트, 개인정보 영향 검토 메모.
- 현재 내부 검토/보류 조건: 내부 기능 검토 가능. 실제 참여자 사용은 개인정보·동의·삭제 정책 전까지 보류.

### A3. 도형 맞추기

- 대상/목적/응답자: 일반 고령자, MCI 진단자, 치매 당사자 중 게임형 활동을 원하는 사용자. 목적은 시각적 주의와 과제 수행 경험 제공이다.
- 근거 문헌·공식 URL·대상: 다중영역 인지 훈련의 한 예로 SUPERBRAIN 연구가 지역사회 고령자와 MCI 고위험군을 다룬다: https://pubmed.ncbi.nlm.nih.gov/32972306/ 및 https://pmc.ncbi.nlm.nih.gov/articles/PMC7056906/
- 원문 원리와 새 설계 차이: SUPERBRAIN은 운동, 인지훈련, 영양, 혈관위험 관리 등 복합 중재다. 현재 도형 맞추기는 단일 게임이며 복합 중재 효과를 주장할 수 없다.
- 현재 상태: 구현됨. `shape_match` 활동과 점수형 완료 기록이 있다.
- 미검증: 난이도 적정성, 오류 피드백의 좌절감, 화면 접근성, 점수 해석 문구.
- 권리/전문가 확인 담당: UX 담당, 접근성 담당, 임상 전문가.
- 검증 방법/통과 조건: 390/768/1280 화면에서 오버플로와 터치 가능 영역 확인, 합성 플레이 기록 저장 확인. 통과율은 합의 필요.
- 보존 증거: 화면 캡처, 테스트 로그, 점수 저장 레코드, 접근성 체크리스트.
- 현재 내부 검토/보류 조건: 내부 데모 가능. 점수를 인지 상태 지표로 표현하는 문구는 보류.

### A4. 문장 읽기

- 대상/목적/응답자: 일반 고령자, MCI 진단자, 치매 당사자 중 읽기·말하기 활동을 원하는 사용자. 목적은 문장 읽기 활동 경험과 발화 연습 후보 검토다.
- 근거 문헌·공식 URL·대상: 디지털 인지활동과 원격 활동의 실행 가능성 근거는 ACTH 계열 디지털 치매 지원 연구, CST/iCST 자료와 함께 검토한다. iCST 공식 자료는 https://www.ucl.ac.uk/international-cognitive-stimulation-therapy/ 이다.
- 원문 원리와 새 설계 차이: 발화·언어 평가는 표준 절차와 검증된 채점이 필요하다. 현재 문장 읽기는 앱 활동이며 진단 음성평가가 아니다.
- 현재 상태: 구현됨. 별도 음성 평가는 차단 화면이 있으며 정확도 검증 전 사용하지 않는 구조다.
- 미검증: 음성 권한 안내, 녹음/비녹음 구분, 발음 점수의 의미, 소음·기기 차이.
- 권리/전문가 확인 담당: 음성/보안 담당, 임상 전문가, 제품 책임자.
- 검증 방법/통과 조건: 합성/더미 흐름으로 권한 거부, 중단, 완료, 저장 필드 확인. 통과율은 합의 필요.
- 보존 증거: 권한 화면 캡처, 음성 미저장/저장 정책, 테스트 로그.
- 현재 내부 검토/보류 조건: 내부 화면 검토 가능. 실제 음성 기반 평가나 진단 문구는 검증 전 보류.

### A5. 일정 준비와 생활 계획 활동

- 대상/목적/응답자: 일반 고령자, MCI 진단자, 초기 치매 당사자, 보호자. 목적은 병원/센터 방문 전 질문 정리, 생활 목표, 일정 변화 준비다.
- 근거 문헌·공식 URL·대상: GREAT 연구는 초기 치매의 개인 목표 기반 인지재활을 평가했다: https://pubmed.ncbi.nlm.nih.gov/30217629/ TIDieR는 중재 설명과 복제 가능성 체크리스트를 제공한다: https://www.equator-network.org/reporting-guidelines/tidier/
- 원문 원리와 새 설계 차이: GREAT는 치료자와 개인 목표 설정, 훈련, 결과 평가를 포함한다. 앱 설계안은 목표·방문 준비 기록 도구로만 다룬다.
- 현재 상태: 제안됨, 미구현.
- 미검증: 목표 문구 안전성, 보호자와 본인 입력 구분, 의료 조언으로 오해될 가능성.
- 권리/전문가 확인 담당: 임상 전문가, 제품 책임자, 법무/컴플라이언스.
- 검증 방법/통과 조건: 화면 목업 검토 후 합성 데이터로 생성-수정-삭제-내보내기 흐름 확인. 통과율은 합의 필요.
- 보존 증거: 목업, 검토 회의록, 버전 문서, 테스트 로그.
- 현재 내부 검토/보류 조건: 내부 목업 검토 가능. 실제 참여자 사용은 기관 절차 전까지 보류.

### A6. 공통 안전·기록 기능

- 대상/목적/응답자: 모든 경로. 목적은 안전한 사용, 감사 가능성, 연구·운영 해석의 분리다.
- 근거 문헌·공식 URL·대상: MRC/NIHR 복합중재 프레임워크는 개발·타당화·평가 단계를 구분한다: https://doi.org/10.1136/bmj.n2061 TIDieR는 개입의 구성요소와 전달 방식을 기록하도록 권장한다: https://www.equator-network.org/reporting-guidelines/tidier/
- 원문 원리와 새 설계 차이: 원문은 연구 보고 기준이다. 앱 설계에서는 콘텐츠 버전, 세션 맥락, 도움 수준, 중단 사유, 기술 문제를 운영 메타데이터로 기록한다.
- 현재 상태: 일부 구현. `training_attempts`에 콘텐츠 버전, 세션 맥락, 도움 수준, 응답 코드 등이 추가되어 있으나 모든 화면의 명시적 중단/불편 UI는 아직 아니다.
- 미검증: 전 활동 공통 적용, 도움 수준과 진단 정보 독립성, 보호자 대리 입력 표시, 삭제·내보내기.
- 권리/전문가 확인 담당: 제품 책임자, 데이터/보안 담당, 임상 전문가.
- 검증 방법/통과 조건: 합성 데이터로 완료, 중단, 기술 문제, 보호자 도움 기록이 서로 구분되는지 확인. 통과율은 합의 필요.
- 보존 증거: DB 스키마, 마이그레이션 테스트, 화면 캡처, 내부 검토 체크리스트.
- 현재 내부 검토/보류 조건: 내부 검토 가능. 실제 참여자 사용은 동의·중단·삭제 정책 확정 전까지 보류.

## 표준 설문 후보 매트릭스

현재 앱의 10문항 자체 점검은 아래 표준 설문으로 이름을 바꾸거나 점수를 해석해서는 안 된다. 아래 도구는 후보이며, 문항·채점·해석을 앱에 넣기 전 권리와 한국어판 사용 조건을 확인해야 한다.

### Q1. SMCQ

- 대상/목적/응답자: 지역사회 일반 고령자 또는 기억 걱정이 있는 사용자. 목적은 주관적 기억 호소 확인이다. 응답자는 본인.

- 원문 원리와 새 설계 차이: 원문은 14개 자기보고 문항과 연구 검증을 포함한다. 앱은 원문 문항·채점표를 허가 없이 복제하지 않으며, 기존 10문항을 SMCQ로 해석하지 않는다.
- 현재 상태: 제안됨, 미구현.
- 미검증: 저작권, 한국어판 원문 사용 허가, 채점·해석 권한, 점수 노출 문구.
- 권리/전문가 확인 담당: 법무/권리 담당, 임상 전문가.
- 검증 방법/통과 조건: 원문 사용허가 문서 확보, 전문가가 목적·대상·응답자 문구를 승인. 통과율은 합의 필요.
- 보존 증거: 라이선스/허가 기록, 전문가 검토표, 버전 문서.
- 현재 내부 검토/보류 조건: 후보 설명 검토 가능. 실제 문항 탑재는 권리 확인 전 보류.

### Q2. KDSQ-C

- 원문 원리와 새 설계 차이: 원문은 정보제공자가 관찰한 변화를 묻는다. 앱 설계에서는 본인 자기보고나 보호자 부담과 섞지 않는다.
- 현재 상태: 제안됨, 미구현.
- 미검증: 문항 사용권, 최신 한국형 권고, 채점 기준, 정보제공자 신원 표시.
- 권리/전문가 확인 담당: 임상 전문가, 법무/권리 담당.
- 검증 방법/통과 조건: 공식 문항 출처와 사용 조건 확인 후 보호자 응답 플로우를 합성 데이터로 검증. 통과율은 합의 필요.
- 보존 증거: 출처 원문, 허가 기록, 응답자 구분 테스트 로그.
- 현재 내부 검토/보류 조건: 후보 설명 검토 가능. 실제 문항 탑재는 보류.

### Q3. K-AD8

- 근거 문헌·공식 URL·대상: Korean AD8 validation: https://pubmed.ncbi.nlm.nih.gov/19561437/ Washington University AD8 terms: https://otm.wustl.edu/ad8-terms-agreement/
- 원문 원리와 새 설계 차이: AD8은 정보제공자 기반 변화 확인 도구다. 앱에서는 보호자 관찰 점수와 사용자 본인 점수를 합산하지 않는다.

## 검증 체크리스트

- 근거/목적/버전: 각 활동과 설문의 출처 URL, 대상, 응답자, 앱 내 목적을 문서화한다.
- 권리/자산: 표준 설문 문항, 채점, 번역, 로고, 음성/이미지 자산의 사용 조건을 확인한다.
- 전문가 검토: 임상 전문가가 진단/치료/효과 문구가 없는지 확인한다.
- 소프트웨어: 합성 데이터로 권한 거부, 완료, 중단, 기술 문제, 삭제, 내보내기, 콘텐츠 버전 저장을 확인한다.
- 사용성/실행 가능성: 기관 절차에 따라 감독 하에서 수행한다. 표본 수와 통과 기준은 합의 필요.
- 효과 검증: 참여자 대상 효과는 별도 연구계획서, 윤리·기관 절차, 통계 계획 이후 진행한다.

## 기업 접촉용 한 문장

MemoryLink는 치매 진단 앱이 아니라, 일반 고령자·MCI 진단자·치매 당사자·보호자가 한 제품 안에서 역할과 도움 수준을 분리해 기록하고, 표준 설문 후보와 인지활동 후보를 권리·전문가·기관 검증 순서에 맞춰 단계적으로 적용하는 생활 지원/검증 준비 플랫폼으로 제안한다.
