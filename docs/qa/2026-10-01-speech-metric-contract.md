# AI 대화의 음성 지표 측정 계약

기준일: 2026-10-01. 사용자 선택: 대화·텍스트 지표를 유지하며, 유효한 발화 시간이 없으면 종합 점수 산출·저장을 차단한다.

## 적용 범위

AI 대화 화면, ChatMessage, ChatSpeechMetrics, LocalAIService 및 해당 회귀 테스트에 적용한다. 음성 진단 중지 화면, 활동 이상감지, DB 스키마, 기존 임상 보고서, 디자인·라우터 작업은 변경하지 않는다. 새 임상 임계값을 도입하지 않는다.

## 측정 정의

| 항목 | 정의 및 결측 처리 |
|---|---|
| 입력 출처 | typed(키보드), voice(STT 원문), editedVoice(STT 후 직접 수정), unknown(출처 미확인). AI 응답은 사용자 지표에서 제외한다. |
| 텍스트 분량 | 모든 사용자 메시지를 공백으로 분리한 토큰 수. 한국어 형태소나 영어 단어 수와 동일하다고 가정하지 않는다. |
| TTR | 소문자로 비교한 고유 공백 토큰 수 / 전체 토큰 수. 구두점은 기존처럼 남긴다. 빈 입력은 null. 타이핑·수정된 STT에서도 텍스트 지표로 표시한다. |
| 발화 시간 | 각 사용자 응답의 실제 음성 구간 길이. AI 대기·타이핑 시간·전체 세션 시간·마이크 청취 제한을 대입하지 않는다. |
| WPM | 모든 사용자 입력이 수정되지 않은 음성이며 각 입력에 양수 실제 발화 시간이 있을 때만 총 토큰 / 총 발화 초 × 60. 하나라도 타이핑·수정·출처 불명·시간 결측이면 null. 마이크로초 단위 합산 후 초로 환산한다. |
| 휴지 비율 | 현재 미측정. STT pauseFor=3초는 종료 설정이며 휴지 측정값이 아니다. 음성 구간·무음 검출·최소 휴지·분모 정의를 확보하기 전에는 산출하지 않는다. |
| 종합 점수/위험 점수 | 빈 텍스트, 토큰 수 0 이하, 결측/비유한/범위 밖 TTR, 결측/비유한/0 이하 WPM 또는 시간은 null이며 is_available=false. 측정 불가를 0점·최고 위험으로 치환하지 않는다. |
| 저장 | 측정 불가 화면은 저장 버튼을 비활성화한다. 저장 함수도 null 점수에서는 반환한다. 텍스트와 출처는 현재 대화 세션 메모리에만 남으며 DB 기록 형식은 확장하지 않는다. |

현재 speech_to_text 경로는 실제 발화 시간을 제공하지 않으므로 음성 입력을 포함한 모든 현재 AI 대화 세션에서 WPM·휴지 비율·종합 점수가 측정 불가다. TTR과 텍스트 분량, AI 대화는 계속 사용할 수 있다. 합성 시간 데이터를 사용하는 단위 테스트가 실제 기기의 발화 시간 측정 구현을 의미하지 않는다.

## 유효 수치에 대한 기존 산식

TTR 가중치, WPM 50/80/160/200 경계, 발화량·문장완결성·반복 감점, 최대 95점과 키워드 위험 점수 계산은 유지한다. 이들은 검증 전 내부 규칙이다. 임상적 정상/위험군 구분 타당성을 이번 변경이나 테스트 통과로 입증하지 않는다. 서비스는 호출자가 제공한 유효 수치의 산술을 검증하며, 입력 출처와 시간 집계는 ChatSpeechMetrics가 담당한다.

## 입력과 비동기 상태

STT 결과를 사용자가 수정하면 editedVoice가 된다. 전송·종료·직접 편집 시 이전 인식 결과가 다음 입력을 덮어쓰지 못하도록 차단한다. AI 응답 대기 중에는 종료·전송·마이크·텍스트 편집을 비활성화한다. 사용자 메시지가 전혀 없으면 분석 결과를 만들지 않는다.

## 연구·통계 인계

현재 TTR은 텍스트 기술통계로만 사용한다. WPM·휴지 비율 결측을 0으로 채워 정상/위험 분류나 평균 계산에 포함하지 않는다. 문헌 대조 단계에서는 언어·과제·전사/토큰화·발화 길이·분모를 일치시켜야 한다. 향후 실제 시간 파이프라인에서는 휴지를 포함하는 speech rate와 제외하는 articulation rate를 먼저 구분하고 버전을 부여한다.

테스터 자료에 필요한 최소 컬럼: 가명 participant_id/session_id, 입력 출처, 과제·언어, 기기/STT 버전, 토큰 수, 고유 토큰 수, 실제 발화 시간의 정의·단위, 휴지 검출 정의, 지표 버전, 결측 사유, 독립 평가값과 그룹 라벨 출처. 실제 자료와 독립 라벨은 이번 단계에서 확보·분석하지 않았다.
